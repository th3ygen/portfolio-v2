# Loadout logos

Eight brand marks, one per gear slot in s01.

Source: Simple Icons (https://simpleicons.org), fetched from
`cdn.jsdelivr.net/npm/simple-icons/icons/<slug>.svg`. Filenames are the
upstream slugs so the provenance of each file is checkable.

The icons are CC0; the marks themselves remain the trademarks of their owners
and are used here only to identify the technologies in the loadout.

Each is a single 24x24 path with no fill attribute, which is what lets the gear
slot use it as a CSS mask and drive the colour itself. Replacing one means
keeping that shape: one path, a 24x24 viewBox, no inline fill.
